# Changelog

## 1.5.0

* Prepared the plugin for public distribution.
* Disabled automatic cleanup by default on new installations.
* Retained the permission-controlled, confirmation-protected bulk action.

## 1.4.0

* Permanently deletes zero-recipient badge definitions.
* Archives recipient-bearing badge definitions while preserving issued badges.
* Uses the Moodle 5 namespaced badge API.

## 1.3.0

* Corrected zero-recipient cleanup to use full deletion rather than archive mode.

## 1.2.0

* Added a course-level bulk cleanup action and command-line cleanup utility.
* Corrected first-install setting handling.

## 1.1.0

* Added cleanup after course restore events.

## 1.0.0

* Initial release with cleanup after course reset events.
